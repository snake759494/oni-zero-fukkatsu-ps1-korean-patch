# 기술 설명

대상: PS1 일본판 『ONI零 ～復活～』(パンドラMAXシリーズ Vol.6, SLPS-03106), 단일 데이터 트랙(MODE2/2352) BIN/CUE.

## 디스크

| 파일 | 내용 | 패치 |
| --- | --- | --- |
| `SLPS_031.06` | 실행파일 | 동료·적 이름 표, 주인공 기본 이름, 이동한 데이터 파일의 섹터 참조 |
| `DATA00.DAT` | 거의 모든 게임 데이터(스크립트·글꼴·그림)를 담은 묶음 | 대사·문자열·글꼴·그림 교체, 커진 파일은 끝에 덧붙임 |
| `*.STR` | 오프닝 등 영상 | 손대지 않음 |

`tools/iso.py`가 ISO9660을 읽고 `tools/disc.py`가 파일을 다시 씁니다. `DATA00.DAT`가 커지면 뒤에 있는 파일을 디스크 끝으로 옮기고 디렉터리 레코드를 고칩니다. 섹터 EDC/ECC는 `tools/cdsec.py`가 다시 계산합니다. 그래서 결과 BIN이 원본보다 큽니다.

## DATA00 안의 파일 참조

`DATA00.DAT`는 2048바이트 섹터 단위로 파일이 이어져 있고, 각 파일 첫 4바이트가 크기입니다. 다른 파일과 실행파일은 `(섹터 수 << 24) | 시작 섹터` 형식의 32비트 값으로 파일을 가리킵니다. `tools/refs.py`가 이 값을 모두 찾아 `refs.pkl`로 만들고, 빌드에서 파일이 커져 제자리에 들어가지 않으면 `DATA00.DAT` 끝에 새로 놓은 뒤 참조를 전부 새 값으로 고칩니다.

## 대사

스크립트 안의 대사는 `04 00 00 00` + 끝 오프셋(4바이트) + Shift-JIS 문자열 + NUL 형식입니다(`tools/strings.py`). 문자열 시작은 같은 파일 안의 상대 오프셋으로 참조됩니다.

- 번역이 원문 자리에 들어가면 제자리에 넣습니다. 길면 원문 자리를 비우고, 비운 자리나 파일 끝에 놓은 뒤 그 문자열을 가리키는 상대 오프셋을 모두 고칩니다(`build.py`의 `patch_script`). 참조를 찾지 못한 문자열은 공백을 빼고 제자리 길이에 맞춰 자릅니다.
- 제어 코드(`^m` 줄바꿈, `^L` 페이지, `^M` 끝, `^N01` 이름, `^Cxxxxxx` 색 등)는 그대로 둡니다.
- 대사 밖의 메뉴·아이템·법술 설명 등은 NUL로 끝나는 문자열을 찾아(`tools/misc_scan.py`) 원문 길이 안에서 제자리에 바꿉니다. 남는 자리는 좁은 공백으로 채웁니다.

## 글꼴

게임 글꼴은 `DATA00.DAT` 0x325d000(와 같은 형식의 사본들)에 있는 2bpp 가변폭 글꼴입니다. Shift-JIS 39행 × 191칸 오프셋 표 + 글리프 데이터(머리 1바이트 = 폭<<4 | 높이)로 되어 있습니다(`tools/font.py`).

- 기호·가나·영숫자(0~3행)는 그대로 두고, 한자 영역의 코드(0x889F부터)를 번역에 쓰인 한글 음절에 차례로 붙입니다.
- 런타임에 이름으로 쓰는 司·狼·丸 글리프와 전각 공백 코드는 피합니다.
- 한글 글리프는 나눔스퀘어 네오 cBd로 그린 뒤 원본처럼 채움·중간색·테두리 3단계로 만듭니다(`tools/kglyph.py`). 공백은 폭 5의 좁은 글리프로 따로 둡니다.
- 쓰이지 않게 된 한자 칸은 `？` 글리프를 가리키게 해서 글꼴 영역 크기를 넘지 않게 합니다.

## 이름

실행파일의 동료·적 이름 표(8바이트 칸)와 이름 길이 표, 주인공 기본 이름(司狼丸 → 시로마루)을 고칩니다. 이름 입력 화면의 가나 표는 한글 음절 표로 바꿉니다(`patch_namegrid`).

## 그림 글자

그림은 PS1 TIM(4/8bpp)입니다. `tools/gfx.py`가 그림을 팔레트 인덱스 배열로 열고, 글자 지우기(채우기·무늬 복사·주변색 메우기)와 한글 그리기(테두리·그림자·안티에일리어싱 선택)를 한 뒤 같은 픽셀 데이터를 가진 모든 사본에 기록합니다. 그림별 명령은 `text/gfx_spec.py`에 있습니다.

- 팔레트가 없는 그림(세이브 화면, 메뉴·전투 UI)은 게임이 실행 중에 회색조 또는 별도 팔레트를 씌우므로 인덱스 번호로 직접 그립니다.
- 전투 명령 메뉴는 원본이 글자·테두리·그림자 세 인덱스만 쓰고 실제 색은 그라데이션이라, 안티에일리어싱 없이 세 인덱스로만 그립니다.
- 픽셀 글꼴(갈무리)은 확대해서 그렸다 줄이면 획이 뭉개지므로 원래 크기로 그립니다.
- 타이틀처럼 그림 요소가 많은 화면은 원본 일본어를 다 지우지 않고 영상 자막처럼 한글을 덧씌웠습니다.

## 테스트 도구

`tools/srv.py`·`c.py`·`emu.py`는 DuckStation을 화면 밖에서 띄워 GDB 원격 프로토콜로 메모리를 읽고, 창 메시지로 키를 보내고, 화면을 찍는 테스트용 도구입니다. 빌드에는 쓰지 않습니다.
