# 오니제로 부활(ONI零 ~復活~) 번역 지침

PS1 일본판 RPG. 헤이안 시대 배경, 주인공 일행(외도환 일족 '은인(隠忍)')이 요마(妖魔)를 퇴치하는 이야기.
원문은 게임 스크립트에서 뽑은 **한 줄 단위** 문자열이며, 파일 순서대로 나열되어 있어 앞뒤 줄이 한 대화를 이룹니다.

## 파일 형식
- 원문 목록은 저장소에 없고 `tools/prepare.py`가 원본 디스크에서 `text/src/dNN.tsv`(`id<TAB>일본어`)로 만듭니다.
- 번역은 `text/ko/dNN.tsv`·`mNN.tsv`에 `id<TAB>한국어`로, 원문과 같은 id를 씁니다. 원문 그대로 둘 줄은 빼도 됩니다.
- `text/ko/fix.tsv`는 번호가 없는 문자열의 수동 교정입니다(`원문 SHA-1 앞 16자리<TAB>한국어`).
- 파일은 UTF-8.

## 제어 코드 (반드시 원문과 똑같이, 같은 위치(대개 줄 끝)에 그대로 둘 것)
- `^m` 줄바꿈, `^L` 입력 대기 후 다음 페이지, `^M` 메시지 끝, `^l`, `^w`, `^W`, `^S`, `^R` 등도 그대로.
- `^N01` 등 `^N`+숫자2자리: 주인공 이름 변수. 그대로 두고 한국어 조사는 받침 유무와 무관하게 쓰이도록 처리 (예: `^N01은(는)` 대신 문장을 바꿔 `^N01 녀석`처럼 조사를 피하거나, 자연스러우면 `^N01,` 처럼 호격으로).
  기본 이름은 '시로마루'(받침 없음)이므로 꼭 필요하면 받침 없는 조사(는/가/를/와/로)를 쓴다.
- `^C` + 6자리 16진수(예 `^Cffff00`)는 글자색. 코드와 6자리 숫자를 그대로 유지하고, 색을 입힐 단어 앞뒤 위치를 의미에 맞게 유지.
- 제어 코드는 영어 대소문자를 바꾸지 말 것.

## 줄 길이
- 각 줄은 **공백 제외 14자 이하**(원문이 15자 이상이면 원문 글자 수 이하). 공백은 좁게 그려지므로 자유롭게 써도 됨.
- 한 대화(`^L`/`^M`으로 끝나기까지의 여러 줄)는 내용을 줄 사이에 자연스럽게 재배분해도 되지만, **각 id 줄은 원래 줄의 제어 코드를 그대로 가져야** 함.
- 선택지(짧은 줄, 예: `休む^m`)는 짧게.

## 문자
- 한글, 숫자, 문장부호만 사용. 쓸 수 있는 부호: `… ！ ？ 、 。 ， ． ・ 「 」 『 』 （ ） ～ ー ― ： ♪ ＋ － ％` 및 원문에 있는 특수기호(㌣, ㌦, ＠, ★ 등 원문에 있던 것은 그대로).
- 느낌표/물음표는 `!` `?` 를 써도 됨(빌드에서 전각으로 바꿈). 쉼표는 `,` 마침표는 `.` 써도 됨.
- 아라비아 숫자 사용 가능(전각으로 바뀜). 영문 알파벳은 꼭 필요할 때만.
- 일본어 가나/한자를 남기지 말 것. (단, 의미 없는 깨진 문자열·한 글자짜리 무의미 한자는 **원문 그대로** 출력)
- 디버그용 문자열(`Ｌａ０１３８`, `Ｍ０１－０２`, `VRM転送`, `デバック`, `ハフマン` 등)은 원문 그대로 둬도 된다.

## 문체
- 자연스러운 한국어 구어. 캐릭터 말투 살리기(거친 남자: 반말·~냐/~다고, 노인: ~구먼/~느니라, 공손: ~습니다/~요, 아이: 귀엽게).
- '妖魔'=요마, '退魔師'=퇴마사, '鬼'=오니(문맥상 일반 도깨비면 '귀신/도깨비' 가능), '神様'=신령님, '御神体'=신체(御神体), '法術'=법술, '神力'=신력, '体力'=체력, '金'(돈 단위)=냥 (예 `金２７０`→`270냥`).
- 일본 고유명사는 아래 용어집의 표기를 따름. 용어집에 없는 인명·지명은 일본어 발음을 국립국어원 표기법에 가깝게(장음 생략) 음역.
